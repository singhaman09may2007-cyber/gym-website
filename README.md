# FitLife Gym & Fitness Website

## Objective
A fully functional gym and fitness website developed as part of the Web Dev and Cloud Foundation coursework using HTML, CSS, and basic JavaScript.

## Features
* **Fitness Programs:** Detailed descriptions of strength, cardio, and yoga classes.
* **Workout Plans:** Structured weekly schedule table.
* **Membership Section:** Interactive form with JavaScript validation for user registration.
* **Health Information:** Essential tips on hydration, nutrition, and rest.

## Technologies Used
* HTML5
* CSS3
* JavaScript (Basic)
